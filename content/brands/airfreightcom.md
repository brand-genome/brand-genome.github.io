## Brand Guidelines

### 2023

#### Brand Summary

##### Mission

- AirFreight.com is a logistics company specializing in airborne deliveries, helping organizations transport and deliver products quickly and efficiently, primarily by air, with a focus on real-time tracking and route optimization for safe and timely shipments [^1].

##### Core Values

- speed
- efficiency
- safety
- reliability
- professionalism

##### Target Audience

- Organizations and businesses in the U.S. and Canada needing fast, reliable air freight and logistics solutions [^2].

##### Personality Traits

- professional
- modern
- trustworthy
- dynamic

##### Visual Identity Overview

- The brand uses a modern, clean visual style centered around a stylized blue star logo, bold sans-serif typography, and a fresh blue-and-white color palette. Visuals emphasize clarity, professionalism, and aviation themes, with consistent logo usage and strict color guidelines [^3].

##### File Format Usage

- For best results in printing or manufacturing, use the vector format of the logo (.eps file format). This type of file ensures the highest quality in crispness and accuracy, no matter how small or large the logo is reproduced.
- For best results on the web, use the vector format of the logo (.svg file format), and for other digital use cases such as PowerPoint, where the .svg file cannot be used. use the raster format of the logo. These are jpg or .png files.
- File Format: .png
- Resolution: 72 dpi
- Usage: This pixel file is best utilized for detailed, high-contrast web graphics due to its smaller size and transparent background. Scaling above 100% leads to a decrease in quality. Save at 2x for smaller graphics such as icons.
- File Format: .eps
- Resolution: Vector
- Usage: This file format. which is the highest quality and infinitely scalable, is the preferred format for spot and CMYK color offset printing, wide-format display, and premium items such as hats, shirts, mugs, and so on.
- File Format: jpg
- Usage: This pixel file is a good alternative for website imagery due to its smaller size. Its lossy compression can comprimize image quality, while scaling above 100% leads to a decrease in quality.
- File Format: .PDF
- Resolution: 300 dpi
- Usage: This secure file format is the preferred file format for high­resolution print items such as brochures, flyers, and posters.
